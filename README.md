2. **토스 & 애플 스타일 플랫 UI + SUIT 폰트**
   - 불필요한 그림자와 노이즈를 제거한 깔끔한 1000px 레이아웃.
   - 스크롤바 유무에 따른 화면 흔들림 0% (`scrollbar-gutter: stable`).
3. **실전 매수 중심 기능**
   - **지역 탭**: `전체`, `서울`, `광명`, `성남`, `안양`, `수원`, `용인` 원클릭 필터링.

   - **원클릭 상세 공고**: 아파트 단지명 클릭 시 법원 경매 상세 페이지 연결.

## 🌐 인터넷 주소로 접속해서 보는 법 (GitHub 무료 배포 3분 가이드)

내 컴퓨터에 파이썬을 깔 필요 없이, 아래 순서대로 **딱 한 번만** 올리시면 평생 무료로 매일 아침 자동 업데이트되는 나만의 경매 사이트 주소가 생깁니다.

### 1단계: GitHub(깃허브)에 파일 올리기
1. [GitHub.com](https://github.com/)에 로그인 후 우측 상단 `+` 버튼 ➔ **[New repository]** 클릭.
2. Repository name에 원하는 이름(예: `my-auction`)을 적고 **[Create repository]** 클릭.
3. 생성된 화면에서 **`uploading an existing file`** 글자를 클릭.
4. 내 컴퓨터의 `09. Home` 폴더 안에 있는 **모든 파일과 폴더**(`.github`, `css`, `data`, `js`, `scripts`, `index.html`, `requirements.txt`, `README.md`)를 마우스로 드래그해서 넣은 뒤 하단 **[Commit changes]** 클릭.

### 2단계: 인터넷 웹사이트 주소(GitHub Pages) 켜기
1. 방금 만든 GitHub 저장소 상단 메뉴의 **[Settings]** 클릭.
2. 왼쪽 메뉴에서 **[Pages]** 클릭.
3. **Branch** 항목에서 `None`을 누르고 **`main`**으로 바꾼 뒤 옆의 **[Save]** 클릭.
4. 약 1분 뒤 새로고침하면 상단에 **`https://내아이디.github.io/my-auction/`** 주소가 나타납니다!
   - 이제 이 주소를 스마트폰이나 PC 즐겨찾기에 등록해 두고 언제든 접속하시면 됩니다.
